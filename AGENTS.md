# GeoLookup

Laravel package source lives in `src/`, configuration in `config/`, and Pest/Testbench tests in `tests/`. Use PHP strict types and the `Moztopia\GeoLookup` namespace. Preserve host-owned middleware, authentication and CORS.

Run Composer validation, Pest and Pint for affected behavior. Do not install software on the host; use an existing compatible PHP runtime or isolated official Docker CLI images. No HTTP server or frontend is needed for package tests.

`VERSION` is the canonical repository source version. Target issue PRs at `develop`. Never commit dependencies, lockfiles, raw acquired data or the separate `wiki/` clone. Dataset licenses and source-code licensing are distinct. Never turn populated-place points or statistical approximations into claims of official administrative boundaries.
