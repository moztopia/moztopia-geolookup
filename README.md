# GeoLookup

GeoLookup (`moztopia/geolookup`) provides local administrative location lookup for Laravel: type-ahead name/postal search, country-specific hierarchies and coordinate lookup using locally installed boundaries.

Detailed documentation is maintained in the [wiki](https://github.com/moztopia/moztopia-geolookup/wiki):

- [Installation and datasets](https://github.com/moztopia/moztopia-geolookup/wiki/Installation)
- [PHP API](https://github.com/moztopia/moztopia-geolookup/wiki/PHP-API)
- [HTTP API and discovery](https://github.com/moztopia/moztopia-geolookup/wiki/HTTP-API)
- [Client SDK generation](https://github.com/moztopia/moztopia-geolookup/wiki/Client-SDKs)
- [Development and validation](https://github.com/moztopia/moztopia-geolookup/wiki/Development)
